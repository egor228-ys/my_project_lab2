# my_project

## Архитектура

Проект состоит из следующих модулей:

| Модуль | Ответственность | Папка |
| :--- | :--- | :--- |
| Auth | Регистрация, вход, профиль | `src/auth/` |
| Catalog | Список товаров, поиск | `src/catalog/` |
| Cart | Корзина, расчёт суммы | `src/cart/` |
| Orders | Оформление заказов | `src/orders/` |
| Payment | Оплата | `src/payment/` |
| Notifications | Уведомления | `src/notifications/` |

Диаграмма модулей: [docs/diagrams/module_diagram.drawio](docs/diagrams/module_diagram.drawio)
